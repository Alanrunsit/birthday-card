# Birthday Countdown

Tells you how many days until my next birthday. On the day itself it prints a random birthday message instead. 🎂

- `main.py` uses `datetime` to find the next birthday and count the days until it
- `bday_messages.py` holds the messages and uses `random` to pick one

To count down to your own birthday, change the month and day in `main.py`.

```bash
python3 main.py
```
